# 动态规划（DP）基础知识点整理

## 一、核心概念

**动态规划**：把原问题拆成**重叠子问题**，记录子问题答案，避免重复计算。

**DP 成立的三个条件**：

1. **最优子结构**：大问题最优解 = 由子问题最优解组合而成
2. **无后效性**：当前状态确定后，未来决策不依赖"如何到达该状态"
3. **子问题重叠**：不同路径会求到同一个子问题（否则用分治即可）

---

## 二、四大要素（写题必答）

| 要素 | 内容 | 示例（Frog 1） |
|------|------|----------------|
| **状态** | `dp[...]` 表示什么 | `dp[i]` = 跳到第 i 块石头的最小代价 |
| **转移** | 状态间递推关系 | `dp[i]=min(dp[i-1]+cost1, dp[i-2]+cost2)` |
| **初始化** | 边界状态值 | `dp[0]=0`，`dp[1]=abs(a1-a0)` |
| **答案** | 最终取哪个状态 | `dp[n-1]` |

> **状态定义是灵魂**。写代码前先用一句话说清 `dp[i]` 的含义。

---

## 三、解题五步法

```
① 定义状态      → dp[i] 表示前 i 个…的…值
② 推导转移方程  → dp[i] = min/max/sum(…dp[j]…)
③ 确定初始化    → dp[0]、dp[1] 的值（边界）
④ 确定遍历顺序  → 保证依赖的状态先算好
⑤ 确定答案      → dp[n]？max(dp[*])？min(dp[*])？
```

---

## 四、两种实现方式

### 1. 递推（填表法）—— 竞赛主流

```cpp
dp[0] = 初始化;
for (int i = 1; i <= n; ++i)
    dp[i] = 转移(dp[i-1], dp[i-2], ...);
cout << dp[n];
```

**优点**：快、无递归开销。  
**缺点**：要先想清遍历顺序。

### 2. 记忆化搜索（递归 + 缓存）

```cpp
int f(int i) {
    if (边界) return 初值;
    if (memo[i] != -1) return memo[i];
    return memo[i] = 转移(f(i-1), f(i-2), ...);
}
```

**优点**：状态复杂/转移不规律时好写，自动只算用到的状态。  
**缺点**：递归开销、可能爆栈。  
**建议**：先写记忆化确认思路，再转递推。

## 五、常见基础模型

### 1. 线性 DP（一维/二维递推）

- **跳石头（Frog）**：`dp[i] = min(dp[i-1]+w1, dp[i-2]+w2)`
- **最大子段和**：`dp[i] = max(a[i], dp[i-1] + a[i])`
- **LIS 最长上升子序列**
  - O(n²)：`dp[i] = max(dp[j]+1)`，j<i 且 a[j]<a[i]
  - O(n log n)：贪心 + `lower_bound`
- **LCS 最长公共子序列**（二维）
  ```
  若 a[i]==b[j]:  dp[i][j] = dp[i-1][j-1] + 1
  否则:          dp[i][j] = max(dp[i-1][j], dp[i][j-1])
  ```

### 2. 背包（最经典）

| 类型 | 转移 | 一维循环方向 |
|------|------|------|
| **01 背包** | `dp[j] = max(dp[j], dp[j-w]+v)` | j **逆序** |
| **完全背包** | 同上 | j **正序** |
| **多重背包** | 二进制拆分 / 单调队列 | — |
| **分组背包** | 每组选一个 | 组内逆序 |

> 记忆口诀：**01 逆序（防重复选），完全正序（允许重复选）**

### 3. 区间 DP

`dp[i][j]` 表示区间 `[i,j]` 的最优值，按**区间长度**枚举。

```cpp
for (int len = 2; len <= n; ++len)
  for (int i = 0; i + len - 1 < n; ++i) {
      int j = i + len - 1;
      for (int k = i; k < j; ++k)
          dp[i][j] = min/max(dp[i][j], dp[i][k] + dp[k+1][j] + w);
  }
```

典型：石子合并、括号匹配、回文分割。

### 4. 树形 DP

后序遍历（先算儿子再算父亲），常带"选/不选"两状态。  
`dp[u][0/1]`，典型：没有上司的舞会。

### 5. 其它基础类型（了解即可）

- **状压 DP**：二进制表示集合，n ≤ 20（TSP）
- **数位 DP**：按位从高到低，记录 tight/lead
- **概率/期望 DP**：通常逆推

## 六、空间优化

**原则：只保留转移需要依赖的旧状态。**

| 依赖情况 | 优化方式 |
|----------|----------|
| 只依赖 `i-1, i-2` | 两个变量滚动 |
| 依赖上一整行 `dp[i-1][*]` | 两个一维数组 / 压成一维 |
| 背包二维 → 一维 | 注意循环方向（01 逆序） |

**Frog 滚动变量示例**：

```cpp
ll p2 = 0, p1 = 0;  // cost[i-2], cost[i-1]
for (int i = 1; i < n; ++i) {
    ll cur = p1 + abs(a[i] - a[i-1]);
    if (i >= 2) cur = min(cur, p2 + abs(a[i] - a[i-2]));
    p2 = p1; p1 = cur;
}
cout << p1;
```

---

## 七、常见坑（高频）

1. **初始化错**：求 min 没设 INF；`dp[0]` 含义搞错
2. **背包方向反**：01 逆序、完全正序
3. **遍历顺序违反依赖**：用到还没算的状态
4. **答案取错**：不一定是 `dp[n]`，可能是 `max/min(dp[*])`
5. **爆 int**：代价/总和用 `long long`
6. **状态定义含糊**：导致转移写不出
7. **计数类忘取模**

---

## 八、复杂度分析

- **时间** = 状态数 × 每个状态的转移代价
  - 例：LIS O(n²) = n 个状态 × 每个 O(n) 转移
  - 背包 O(nW) = n 个物品 × W 个容量
- **空间** = 状态数（可滚动优化）

## 九、学习路线

```
线性 DP（Frog、最大子段和、LIS、LCS）
    ↓
背包（01 → 完全 → 多重 → 分组）
    ↓
区间 DP → 树形 DP → 状压 DP → 数位 DP → DP 优化
```

**练习方法**：每道题先在纸上回答"状态/转移/初始化/答案"四问，再写代码。
